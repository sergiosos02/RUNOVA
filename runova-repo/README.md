# RUNOVA

Red social deportiva: running/ciclismo, nutrición, eventos y comunidad.

## Contenido de este repositorio

- `runova.html` — Demo web funcional (mobile-first). Ábrela directamente en el navegador
  o súbela a GitHub Pages / Vercel / Netlify para probarla online. No tiene backend:
  los datos se guardan en el `localStorage` del navegador de cada persona.
- `supabase_schema.sql` — Esquema completo de base de datos para Supabase/PostgreSQL
  (tablas, relaciones, índices y políticas de Row Level Security). Pégalo entero en el
  SQL Editor de un proyecto de Supabase y ejecútalo.
- `GUIA_EXPO_SUPABASE.md` — Guía paso a paso para migrar la demo a una app real en
  React Native + Expo conectada a ese Supabase.
